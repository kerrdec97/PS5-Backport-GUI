# Compatibility and test status

PS5 Backport does **not** publish a compatibility percentage. Results depend on the game, its version, the console
firmware, the console model and the options used, so one number would be misleading.

## Result levels

| Level | Meaning |
|---|---|
| **Build completed** | The program produced a backport ZIP. Nothing about the console is known yet. |
| **Static validation passed** | The build passed the program's offline checks (import audit across FW 4.03–13.60, audio check, signature and package checks). Every completed build is at this level. **This is not a test result.** |
| **Hardware launch tested** | Someone launched it on a stated console model and firmware and reached the menu. |
| **Extended gameplay tested** | Played for a meaningful time (state how long), including saving and loading. |
| **Reported working by a user** | A user says it works, with the model and firmware. Not independently checked. |
| **Known issue** | A reproducible problem on a stated model and firmware, with an issue link. |
| **Untested** | No result for that model and firmware. |

A result on a base PS5 says nothing about a PS5 Pro, and a result on one firmware says nothing about another.

## Reporting a test result

Open an issue (or comment on the game's existing issue) with:

- game title, PPSA ID and game version;
- exact firmware and console model (original, Slim or Pro);
- program version and options (Target SDK, PS5 Pro fix);
- the level reached from the table above, and how long you played.
