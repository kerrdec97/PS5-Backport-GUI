# Security

Do not post credentials, personal data, proprietary binaries or exploit details in public bug reports. For a sensitive security concern, contact the maintainer through [their GitHub profile](https://github.com/kerrdec97) to arrange a private reporting route before sending details.

Routine technical bugs must use [GitHub Issues](https://github.com/kerrdec97/PS5-Backport-GUI/issues). Review logs before attaching them.
