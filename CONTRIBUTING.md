# Contributing

PS5 Backport is currently closed source. Contribute through testing, useful diagnostic evidence, documentation feedback and [feature requests](https://github.com/kerrdec97/PS5-Backport-GUI/issues/new?template=feature_request.yml).

All technical bugs belong in [GitHub Issues](https://github.com/kerrdec97/PS5-Backport-GUI/issues/new?template=bug_report.yml). Include exact firmware, console model, game/PPSA/version, build identifier, options, reproduction steps and logs or meaningful alternative evidence. Read [the reporting guide](docs/REPORTING_ISSUES.md) and redact private data. Do not upload commercial game files or proprietary binaries.

Maintainers label incomplete reports `needs-information`, state what is missing and allow 14 days for a response before closure. Reopen or resubmit when the evidence is available. Never mark a problem fixed without verification.
